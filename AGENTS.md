# AGENTS.md

Guidance for coding agents working on **ISS: Last Survivor** (Godot 4.3+, GDScript, 2D).

## Project overview

An invasive alien species has killed everyone aboard the ISS except the main character (MC).
The station is badly damaged. The MC must repair it while the alien hunts them, then escape
to the outside-access area, change into a spacesuit and open the shaft to blow the alien into space.

## Game rules (these are requirements - do not change them without being asked)

### Setting and physics
- 2D game, viewed from the side/top; **zero gravity** everywhere. Movement is thrust-based and floaty.
  `physics/2d/default_gravity` stays `0.0`. Never add gravity or a "floor".

### Controls - the player may ONLY use these keys
| Key | Action |
|---|---|
| Arrow keys | Thrust in that direction; the aim turns smoothly (`AIM_TURN_DEG` in `player.gd`) toward the held direction, so a tap leaves it at any angle (360 degrees) |
| `Z` | Fire the stun weapon |
| `SPACE` | Hold to interact (repair consoles, suit locker, shaft lever); also "retry"/"play again" |

No mouse, no WASD, no other keys. Optional webcam face control (`tools/face_control.py` -> UDP -> `scripts/face_input.gd`) only presses these same six actions (head up/down/left/right = arrows, mouth open = `Z`, blink/eyes closed = `SPACE`); it adds no new actions. Input actions are registered in code in `main.gd` (`_setup_input`).

### The alien
- It **cannot be killed**, only **stunned**.
- The stun weapon (`Z`) stuns for **exactly 3 seconds** (`STUN_SECONDS` in `player.gd`).
  While stunned the alien is harmless and has no thrust.
- Contact with an un-stunned alien = **player death**, followed by an automatic **restart** of the level
  (3 s countdown, `SPACE` to retry sooner).

### Win condition (in this order)
1. Repair **all 5 systems** (hold `SPACE` at each console) - this unlocks the airlock door.
2. Go to the airlock (the outside-access area) and **change into the spacesuit** (locker).
3. Pull the **shaft release lever** (requires the suit; refuses without it). The player is
   **tethered** to the ISS (tether length is capped) while decompression pulls everything toward the shaft.
4. The **alien is sucked out** of the shaft -> victory. The player must survive until then
   (stun the alien if it gets close; a sucked-out alien is still lethal until it leaves).

## Project layout

- `project.godot` - config (main scene: `scenes/main.tscn`)
- `scenes/main.tscn` - a single `Node2D`; the whole level is built in code
- `scripts/main.gd` - level generation, nav grid (A*), interactions, HUD, game state, win/death
- `scripts/player.gd` - zero-g movement, stun bolt (with aim assist), suit, tether
- `scripts/alien.gd` - hunting AI (A* via `main.nav_path`), stun, vacuum behaviour, sprite drawing
- `scripts/face_input.gd` - UDP receiver (port 4242) that mirrors webcam face states onto the input actions
- `tools/face_control.py` - MediaPipe webcam tracker (needs `tools/requirements.txt`)
- `tests/smoke_test.gd` - headless full-playthrough test

Art:
- `assets/alien.png` - alien sprite (artwork faces left; `alien.gd` mirrors it toward the player)
- `assets/astronaut.png` - pixel-art astronaut (drawn with nearest-neighbour filtering)
- `assets/space_bg.jpg` - Milky-Way starfield background (user-supplied, upscaled 2x); `main.gd` draws it on a `CanvasLayer` behind the level, cover-fitted, drifting/breathing with player parallax, plus a second additive mirrored nebula layer (`bg_glow`), pulsing colour clouds, depth-layered twinkling stars with glints, and shooting stars
- `assets/iss_interior.jpg` - station-interior art (ISS-style module views: equipment racks, cables, handrails, hatches, light strips), generated by `tools/gen_interior.py` (needs Pillow + numpy; re-run it after changing the map). **Exactly map-sized** (`W*TS` x `H*TS` = 2784x1536); `main.gd` draws it under the floor tiles 1:1. If you change `W`, `H` or `TS`, edit `TS/W/H` and the `ROOMS`/`CORRIDORS` lists in `tools/gen_interior.py` and regenerate it.
- Textures are loaded through `main.load_tex()`; if a PNG is missing the code falls back to the old procedural drawing.
- Repairable props are animated machines drawn in `main.gd` (`_draw_machine` -> `_m_oxygen`, `_m_comms`, `_m_core`, `_m_coolant`, `_m_hull`, `_m_locker`, `_m_lever`). Each reacts to broken / being repaired (`it.active`, `it.progress`) / fixed (`it.done`).
- Walls, door, hatch, HUD and other effects are still drawn procedurally with `_draw()`. There are no audio assets.

## Setup / run / test commands

- Run the game: open the folder in Godot 4.3+ and press F5, or `godot --path .`
- Import / check for script errors: `godot --headless --path . --import`
- Run tests (must print `RESULT: ALL PASSED`): `godot --headless --path . -s res://tests/smoke_test.gd`
  - Log lines `Parameter "current_scene" is null` from the test run are expected (the test adds the scene manually).

## Code style

- GDScript, tabs for indentation, type hints on function signatures and where inference is clear.
- Constants in `UPPER_SNAKE_CASE`; gameplay tuning values live at the top of each script.
- Keep gameplay rules in the scripts that own them (stun -> `player.gd`/`alien.gd`, flow -> `main.gd`).
- Do not use `class_name`; scripts reference each other through `preload` and injected `main` references.

## Testing instructions

- After any gameplay change run the smoke test; add a check to `tests/smoke_test.gd` for new rules.
- If you change the map in `_build_grid()`, make sure every console, the locker and the lever are still
  reachable (the test teleports to them but the alien AI needs a connected nav grid).

## Do not

- Do not add keys/controls beyond arrows, `Z` and `SPACE`.
- Do not make the stun last anything other than 3 seconds, or let the alien die.
- Do not add gravity.
